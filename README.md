# Portafolio de la Sesión 1 - Algoritmo o IA

Este repositorio contiene los tres ejercicios desarrollados durante las sesiones:

## 📁 Estructura y Ejercicios

1. **Ejercicio 1 – Algoritmo**
   - **Carpeta:** `/ejercicio-1`
   - **Descripción:** Algoritmo en PSeInt diseñado para ordenar tres números de menor a mayor, contemplando casos de números iguales.

2. **Ejercicio 2 – Archivo descargable**
   - **Carpeta:** `/ejercicio-2`
   - **Descripción:** Archivo obtenido y generado durante la actividad práctica de la sesión.

3. **Ejercicio 3 – Página web con IA**
   - **Carpeta:** `/ejercicio-3`
   - **Descripción:** Página web desarrollada con herramientas de Inteligencia Artificial.
   - **Prompt utilizado:** 
     > *"Crea una página web minimalista en un solo archivo HTML y CSS que muestre una tarjeta de presentación personal con un título, una breve descripción de bienvenida y un botón interactivo que cambie de color al hacer clic."*# Portafolio-sesion-1
